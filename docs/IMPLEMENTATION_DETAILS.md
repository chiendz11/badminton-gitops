# Implementation Details (Pure Declarative Kustomize Refactor)

This repository implements the Pure Declarative Kubernetes layout adapted from `MaintAI-gitops`:

- **Bootstrap & Root Apps**: [`bootstrap/local/`](../bootstrap/local/) and [`bootstrap/production/`](../bootstrap/production/) point Argo CD at [`applications/local/`](../applications/local/) and [`applications/`](../applications/).
- **Production Addons & Workloads**: Modular Argo CD Applications under [`applications/`](../applications/) and [`applications/addons/`](../applications/addons/) manage namespaces, gp3 StorageClass, default-deny NetworkPolicies, External Secrets Operator + ClusterSecretStore, Metrics Server, Prometheus/Grafana (`kube-prometheus-stack`), AWS Load Balancer Controller, ExternalDNS, Cert-Manager, Argo CD Image Updater (`1.5.0`), the 11 production workloads ([`environments/production/workloads/`](../environments/production/workloads/)), and ALB Ingress ([`environments/production/edge/`](../environments/production/edge/)).
- **Local Staging**: [`local/platform/`](../local/platform/) and [`local/workloads/`](../local/workloads/) plus [`environments/local/`](../environments/local/) mirror production separation cleanly (zero secrets in ConfigMaps, ExternalSecrets backed by LocalStack, CoreDNS service discovery, zero `:latest` application tags).
- **Removed Legacy Mechanisms**: Python contract compilers (`automation/`), `config/`, `contracts/`, JSON release state (`state/*.json`, `release.json`), and imperative repository-dispatch release workflows were removed in favor of Kustomize-only manifests and native Argo CD Image Updater PRs.
